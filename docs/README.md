# Paseka documentation

Docs are grouped by immersion depth. Feature specs under `specs/` are **not** published on the site; see [Specs index](plans/specs-index.md).

## New here?

Follow the shortest path from the model to a running colony:

1. [Principles](idea/principles.md) — understand choreography and Flight Trail identity.
2. [Colony layout](guide/colony-layout.md) — initialize project and machine-local config.
3. [Bee config](guide/bee-config.md) and [prompt templates](guide/prompt-templates.md) — configure roles.
4. [CLI first-time setup](guide/cli.md#first-time-setup) — start NATS, run diagnostics, and dispatch work.

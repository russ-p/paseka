Queen Console Next — preview bundle not built

This paseka binary was compiled without the redesigned console. The preview bundle is a build artifact and is not committed to the repository, so go install never carries it — build the frontend first, then the Go binary: 

pnpm --dir web install --frozen-lockfile
pnpm --dir web build
go build -o paseka ./cmd/paseka

Release archives and the container image already do this. The legacy console at / is unaffected either way.
